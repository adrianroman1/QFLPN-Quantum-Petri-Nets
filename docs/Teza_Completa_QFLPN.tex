\begin{abstract}
Prezenta teză introduce un formalism operatorial original — Rețele Petri Logice Fuzzy Cuantice (QFLPN) — și o suită software multi‑limbaj proiectată pentru a asigura proprietatea \emph{deadlock‑free} și latență deterministă sub $15\,\mathrm{ms}$ la scară asimptotică critică de
\[N = 3\cdot 10^{7}\ \text{stări}.\]
Modelul fuzionează funcțiile de apartenență fuzzy cu parametrizare continuă și operatorii unitari din spații Hilbert complexe $\mathbb{C}^{2^{n}}$. Lucrarea conține rezultate teoretice (demonstrații complete pentru Teorema punctului fix (Banach) în $B(\mathcal{H})$, Teorema lui Egorov, elemente de Radon‑Nikodym aplicate pentru indicele Z), proiectare arhitecturală și implementări software (Python/PennyLane, Java HPC, MATLAB). Implementările optimizează reprezentarea operatorilor prin CSR/TT și permit offload pe GPU (cuTENSOR/cuSPARSE) pentru workload‑uri masive. 
\end{abstract}

\chapter{Stadiul actual în modelarea cu Rețele Petri și sisteme cuantice}
\section{Rețele Petri clasice: definire, marcaje și dinamica firing‑urilor}

Rețelele Petri sunt un formalism bine stabilit pentru modelarea sistemelor concurente şi distribuie. Formal, o rețea Petri este un tuplu \((P,T, F, W, M_0)\) unde:
\begin{itemize}
\item $P = \{p_1,\dots,p_{|P|}\}$ este mulțimea locurilor;
\item $T = \{t_1,\dots,t_{|T|}\}$ este mulțimea tranzițiilor;
\item $F \subseteq (P\times T) \cup (T\times P)$ este relația de incidență (arce directed);
\item $W:F\to\mathbb{N}_{>0}$ reprezintă greutățile arcelor;
\item $M_0:P\to\mathbb{N}$ este marcajul inițial.
\end{itemize}

Un marcaj $M$ este un vector de dimensiune $|P|$ iar tranziția $t$ este sensibilă (enabled) față de $M$ dacă pentru toate locurile $p$ cu arc $(p,t)$ se îndeplinește $M(p) \ge W(p,t)$. Executarea (firing) lui $t$ actualizează marcajul conform:

\[ M' = M - W(\cdot,t) + W(t,\cdot), \]

unde vectorii $W(\cdot,t)$, respectiv $W(t,\cdot)$ sunt coloanele/linile corespunzătoare din matricea de incidență globală. O formulare matricială a evoluției discrete, într‑un pas, este:

\[ M_{k+1} = M_k + C u_k, \]

unde $C$ este matricea de incidență (coloane pentru tranziții), iar $u_k$ este vectorul binar (sau vectorul de multiplicatori pentru firing‑uri multiple) care indică tranzițiile care s‑au declanșat.

Această formulare este elegantă dar în practică, pentru sisteme cu $|P|$ mare, stocarea și actualizarea matricelor devin prohibitvenă — costul spațial şi temporal crește foarte rapid, iar analizorii tradiționali ajung la limite: enumerarea spațiului stării și verificarea proprietăților își pierd scalabilitatea.

\section{Explozia spațiului stărilor la scala $N = 3\cdot 10^{7}$}

Considerând o topologie de rețea cu $n$ componente binare combinate (fiecare loc are două stări posibile), numărul stărilor compozite este $2^n$. În mod realist, sistemele de interes pot avea un spațiu de stare efectiv de ordinul $N\approx 3\cdot 10^{7}$ sau mai mult. Un exemplu simplificat: dacă fiecare din cele $m$ subsisteme contribuie cu $d_i$ stări, atunci spațiul compozit are cardinalitate $\prod_i d_i$. Practic, acest lucru implică:

\begin{itemize}
\item Necesitatea reprezentărilor sparse și a operațiilor lazy (pe vectori) pentru a evita alocarea explicită a întregului produs Kronecker;
\item Folosirea metodelor de reducere a dimensiunii (projecții pe subspații invariante) și a tehnicilor de factorizare (TT/MPS) pentru a manipula stări foarte mari cu memorie polinomială în loc de exponențială;
\item Adoptarea unei arhitecturi software care permite offload către acceleratoare (GPU), pipeline‑uri de streaming și paralelizare la nivel fine‑grained.
\end{itemize}

Fenomenele numerice importante asociate acestei scale includ pierderea de precizie numerică prin propagarea erorilor de trunchiere, degradarea condiționării operatorilor și costul comunicațiilor în arhitecturi distribuite. Pentru un sistem cu $N=3\cdot10^{7}$ stări, chiar stocarea vectorului de stare pe 8‑byte double implică aproximativ 240 MB — aparent gestionabil — dar operatorii (matrici) și produsele Kronecker asociate pot conduce la cerințe mult mai mari fără compresie.

\section{Spații Hilbert complexe $\mathbb{C}^{2^{n}}$ și reprezentările matriciale}

Un qubit este descris de un vector normalizat $|\psi\rangle = \alpha|0\rangle + \beta|1\rangle$ în $\mathbb{C}^{2}$. Pentru $n$ qubiți, starea pură este un vector din tensorul $\mathcal{H}=\mathbb{C}^{2^{n}}$. Operatorii pe acest spațiu, cum ar fi porțile unitare și matricile de densitate, sunt matrice de dimensiune $2^{n}\times 2^{n}$.

Matricea de densitate reprezintă stări mixte și are proprietățile:

\[ \rho = \rho^{\dagger}, \qquad \rho \succeq 0, \qquad \mathrm{Tr}(\rho) = 1. \]

Operatorii de observabilă sunt hermitici, iar evoluția în absenta mediului se face prin operatori unitari

\[ U(t) = e^{-i H t / \hbar}, \]

unde $H$ este Hamiltonianul sistemului. În practică, pentru modelarea rețelelor Petri cuantice, se asociază fiecărui loc operatorul local $\rho_i$ și se construiește operatorul global prin produs tensorial:

\[ \rho_{global} = \bigotimes_{i=1}^{n} \rho_i. \]

Din punct de vedere computațional, nu se formează produsul tensorial explicit; în schimb se implementează operații care acționează asupra vectorilor de stare folosind proprietățile Kronecker, de exemplu:

\[ (A \otimes B)\,\mathrm{vec}(X) = \mathrm{vec}(B X A^{T}). \]

Această identitate permite realizarea operațiilor pe produsul tensorial fără materializarea matricii complete, reducând drastic costurile memoriei la condițiile potrivite.

\section{Matrici de densitate și canale CPTP în QFLPN}

În QFLPN, tranzițiile pot fi modelate fie ca unitare parametrizate (când operaţiunea este deterministă şi reversibilă), fie ca canale complet pozitive și trace‑preserving (CPTP) pentru a modela zgomotul, pierderile sau observațiile parţiale. Un canal CPTP are reprezentarea Kraus:

\[ \mathcal{E}(\rho) = \sum_{\alpha} K_{\alpha} \rho K_{\alpha}^{\dagger}, \qquad \sum_{\alpha} K_{\alpha}^{\dagger}K_{\alpha} = I. \]

Acest formalism este esenţial pentru a integra efectele mediului sau pentru a regla acţiunea fuzzy a unei tranziţii: coeficienţii Kraus pot fi funcţii ale parametrilor fuzzy, oferind o legătură naturală între logica fuzzy şi canale cuantice.

\section{Descompunerea spectrală și Teorema Artin‑Wedderburn}

Teorema Artin‑Wedderburn, în forma sa pentru algebre semisimple finite‑dimensional, afirmă că o astfel de algebră este izomorfă cu o sumă directă de algebre matriceale peste diviziuni. În contextul operatorilor matriciali, aceasta echivalează cu posibilitatea blocării operatorului în subspații ireductibile. Mai formal, pentru o algebră semisimplă $\mathcal{A}$ există izomorfismul:

\[ \mathcal{A} \cong \bigoplus_{i=1}^{k} M_{n_i}(D_i), \]

unde $D_i$ sunt corpi/algabre de diviziuni. Aplicat la operatorii rețelei, acest lucru permite construcția proiectoarelor centrale $e_i$ astfel încât se separă partea dinamică în componente independente:

\[ 1 = \sum_{i} e_i, \qquad e_i e_j = 0\ (i\ne j), \qquad e_i^2 = e_i. \]

Aplicațiile practice includ: izolarea erorilor locale, reducerea calculelor la blocuri şi compresia reprezentărilor matriceale.

\section{Analiza funcțională: spații Banach și trunchieri Taylor pentru $e^{-iHt}$}

În spațiul Banach al operatorilor cu norma operatorială, exponentiala lui $H$ este dată de serie:

\[ e^{-iHt/\hbar} = \sum_{m=0}^{\infty} \frac{(-i t/\hbar)^m}{m!} H^m. \]

Dacă $\|H\| < \infty$, seria converge absolut şi uniform pe orice interval limitat de $t$. Pentru aplicare numerică, definim trunchierea de ordin $k$:

\[ S_k(t) = \sum_{m=0}^{k} \frac{(-i t/\hbar)^m}{m!} H^m, \]

şi definim eroarea de trunchiere $E_k(t) = e^{-iHt/\hbar} - S_k(t)$. Prin estimare se obţine:

\[ \|E_k(t)\| \le \frac{(|t|\|H\|/\hbar)^{k+1}}{(k+1)!} \left( 1 + \frac{|t|\|H\|/\hbar}{k+2} + \cdots \right) \le \frac{(|t|\|H\|/\hbar)^{k+1}}{(k+1)!} e^{|t|\|H\|/\hbar}. \]

Această bound permite alegerea lui $k$ dată de toleranţa numerică dorită. În practică, pentru simulări la scară mare, algoritmii folosesc expuneri adaptative, factorizări exponentiale (ex: Trotter‑Suzuki), sau metode Krylov subspaţiu pentru a evita trunchierile explicite foarte costisitoare.
