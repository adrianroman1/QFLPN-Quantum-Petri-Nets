# Checklist Doctorat – Obiectiv Excelent / Summa cum laude

## 1. Scopul documentului

Acest document este registrul de control pentru finalizarea
doctoratului și pentru pregătirea dosarului științific.

Obiectivul urmărit:

**Calificativ: Excelent**
  
**Mențiune: Summa cum laude**

Conform regulamentului instituțional UTCN, calificativul
„Excelent” corespunde mențiunii „Summa cum laude”.

Acest document nu reprezintă o garanție a acordării calificativului.
Decizia finală aparține organismelor academice competente, conform
procedurilor UTCN în vigoare.

# 6. Obiectivul de publicații

Obiectiv intern de lucru:

**10 publicații științifice**

Nu se consideră automat că:

`10 publicații = Summa cum laude`

Publicațiile reprezintă o componentă a profilului științific și a
evaluării activității, dar calificativul final este decis conform
procedurilor academice aplicabile.

## Strategia de autorat

- [ ] publicații cu autor principal
- [ ] publicații cu contribuție semnificativă
- [ ] publicații în venue-uri relevante
- [ ] acoperire metodologică a contribuțiilor tezei
- [ ] rezultate experimentale publicate
- [ ] rezultate teoretice publicate
- [ ] rezultate software / HPC documentate unde este relevant

# 14. Regula de aur

Nu marcăm o condiție ca îndeplinită doar pentru că „pare
îndeplinită”.

Pentru fiecare criteriu:

**CERINȚĂ → DOVADĂ → VERIFICARE → STATUS**

Statusuri:

- `TODO`
- `IN PROGRESS`
- `DONE`
- `VERIFIED`
- `BLOCKED`

Obiectivul final este ca înainte de susținerea publică toate
criteriile relevante să fie în stare:

**VERIFIED**
