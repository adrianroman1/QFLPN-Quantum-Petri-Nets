No benchmark measurement is considered verified
solely because a benchmark script or CSV schema exists.

A benchmark result requires:
    - actual execution;
    - retained CSV data;
    - execution log;
    - environment information;
    - independent validation;
    - source revision identification;
    - SHA-256 checksums.

========================================
5. ACCEPTANCE POLICY
========================================

A successful JUnit run establishes only the behavior
covered by the tests executed on that source revision.

It does not independently establish:
    - large-scale performance;
    - measured speedup;
    - measured time reduction;
    - peak memory consumption;
    - reproducibility of an experimental result.

Performance claims must be supported by actual
benchmark evidence.
